# QA Portfolio: Manual Testing (SauceDemo)

Данный репозиторий представляет собой портфолио ручного тестировщика. В качестве объекта тестирования выбран учебный интернет-магазин [SauceDemo](https://www.saucedemo.com/).

## 📁 Структура проекта:
- **`manual-testing/test-plan.md`** — стратегия и объем тестирования.
- **`manual-testing/checklist.md`** — чек-лист регрессионных проверок.
- **`manual-testing/test-cases/`** — детальные тест-кейсы (логин, корзина, checkout).
- **`manual-testing/bug-reports/`** — 3 подробных баг-репорта с шагами воспроизведения.
- **`manual-testing/test-summary.md`** — итоговый отчет о тестировании.
- **`api-testing/`** — описание ручного тестирования API (Postman).

## 🛠 Инструменты и навыки:
- **Тест-дизайн:** классы эквивалентности, граничные значения, негативные сценарии.
- **Баг-трекинг:** составление отчетов (Severity/Priority).
- **API:** Postman/ (GET, POST запросы, проверка статус-кодов).
- **Git/GitHub:** ведение документации в репозитории.

## 🚀 Как просмотреть проект:
Вы можете просто открыть любой `.md` файл в этом репозитории. GitHub отрендерит его в удобочитаемом виде (таблицы, списки, форматирование).
