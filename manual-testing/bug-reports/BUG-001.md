# Баг-репорт: BUG-001

**Заголовок:** [Каталог товаров] У пользователя `problem_user` отображаются некорректные изображения товаров
**Серьезность (Severity):** Major (Значительная)
**Приоритет (Priority):** High (Высокий)
**Статус:** Open

### Окружение:
- ОС: Windows 10 
- Браузер: Google Chrome Версия: 155.0.8059.86
- Тестовый стенд: https://www.saucedemo.com/

### Шаги воспроизведения:
1. Открыть страницу авторизации https://www.saucedemo.com/
2. В поле `Username` ввести: `problem_user`
3. В поле `Password` ввести: `secret_sauce`
4. Нажать кнопку `Login`
5. Обратить внимание на изображения товаров в каталоге.

### Ожидаемый результат:
На странице каталога для каждого товара отображается его уникальное изображение, соответствующее названию и описанию (например, рюкзак, велосипед, футболка).

### Фактический результат:
На странице каталога для всех товаров отображается одно и то же изображение (картинка собаки). Изображения других товаров не подгружаются или подменяются. Это вводит пользователя в заблуждение и делает невозможным визуальную идентификацию товара.

### Анализ и комментарий тестировщика:
Данный дефект воспроизводится стабильно (100%) только при авторизации под аккаунтом `problem_user`. При входе под `standard_user` изображения отображаются корректно. 
Скорее всего, проблема связана с тем, как бэкенд отдает данные об изображениях для этого конкретного тестового пользователя (возможно, в базе данных для этого юзера прописаны неверные пути к картинкам).
