# Баг-репорт: BUG-002

**Заголовок:** [Сортировка] Не работает сортировка товаров по цене у пользователя `problem_user`
**Серьезность (Severity):** Major (Значительная)
**Приоритет (Priority):** Medium (Средний)
**Статус:** Open

### Окружение:
- ОС: Windows 10 
- Браузер: Google Chrome Версия: 155.0.8059.86
- Тестовый стенд: https://www.saucedemo.com/

### Шаги воспроизведения:
1. Авторизоваться под пользователем `problem_user` (пароль `secret_sauce`).
2. На странице каталога найти выпадающий список сортировки (справа сверху).
3. Выбрать опцию `Price (low to high)`.
4. Посмотреть на порядок отображения товаров и цены.

### Ожидаемый результат:
Товары отсортированы по возрастанию цены (от самой дешевой к самой дорогой). Например: $7.99, $9.99, $15.99 и т.д.

### Фактический результат:
Порядок товаров не меняется. Сортировка по цене не работает. При этом в самом выпадающем списке выбранное значение отображается верно, но не выбирается.

### Анализ и комментарий тестировщика:
Дефект воспроизводится только под аккаунтом `problem_user`. Под `standard_user` сортировка работает корректно. Проблема, вероятно, кроется в обработчике события `onChange` для выпадающего списка, который для этого пользователя возвращает ошибку или не срабатывает вовсе.
