# Баг-репорт: BUG-003

**Заголовок:** [Checkout] Невозможно ввести фамилию (Last Name) при оформлении заказа у пользователя `problem_user`
**Серьезность (Severity):** Critical (Критическая)
**Приоритет (Priority):** High (Высокий)
**Статус:** Open

### Окружение:
- ОС: Windows 10 
- Браузер: Google Chrome Версия: 155.0.8059.86
- Тестовый стенд: https://www.saucedemo.com/

### Шаги воспроизведения:
1. Авторизоваться под пользователем `problem_user` (пароль `secret_sauce`).
2. Добавить любой товар в корзину.
3. Перейти в корзину и нажать `Checkout`.
4. На странице ввода данных (`Checkout: Your Information`) попытаться ввести текст в поле `Last Name`.

### Ожидаемый результат:
Пользователь может свободно вводить символы в поле `Last Name`. Форма успешно отправляется при нажатии кнопки `Continue`.

### Фактический результат:
Поле `Last Name` не принимает ввод. При попытке напечатать текст ничего не происходит, символы не отображаются. Из-за этого невозможно завершить оформление заказа (кнопка `Continue` выдает ошибку о том, что поле обязательно для заполнения).

### Анализ и комментарий тестировщика:
Это блокирующий дефект для бизнес-процесса покупки. Под аккаунтом `standard_user` ввод работает корректно. Вероятно, для `problem_user` навешан атрибут `readonly` на это поле ввода или сломан скрипт валидации.
