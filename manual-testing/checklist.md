**Окружение:** Google Chrome Версия: 155.0.8059.86, пользователи `standard_user` и `problem_user`.

### 1. Авторизация
- [x] Вход с валидными данными (`standard_user`)
- [x] Вход с невалидным паролем
- [x] Вход с пустыми полями
- [x] Вход заблокированного пользователя (`locked_out_user`)
- [ ] Вход с невалидным логином (проверено, работает корректно)
