# Тест-кейсы: Модуль оформления заказа (Checkout)

**Тестируемая страница:** https://www.saucedemo.com/checkout-step-one.html
**Окружение:** Google Chrome Версия: 155.0.8059.86, аккаунт `standard_user`.

| ID | Название | Предусловия | Шаги | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-CHK-01** | Успешное оформление заказа | В корзине есть товар, нажата кнопка `Checkout` | 1. Ввести `Ivan` в поле First Name.<br>2. Ввести `Ivanov` в поле Last Name.<br>3. Ввести `12345` в поле Zip/Postal Code.<br>4. Нажать `Continue`.<br>5. На странице подтверждения нажать `Finish`. | Пользователь перенаправлен на страницу `checkout-complete.html`. Отображается сообщение "Thank you for your order!". | Pass |
| **TC-CHK-02** | Оформление с пустым полем Last Name | В корзине есть товар, нажата кнопка `Checkout` | 1. Ввести `Ivan` в поле First Name.<br>2. Оставить поле Last Name пустым.<br>3. Ввести `12345` в Zip Code.<br>4. Нажать `Continue`. | Появляется сообщение об ошибке: *"Error: Last Name is required"*. Переход не осуществляется. | Pass |
| **TC-CHK-03** | Ввод фамилии под problem_user | Авторизован `problem_user`, в корзине есть товар | 1. Перейти к оформлению заказа.<br>2. Попытаться ввести текст в поле Last Name. | Поле должно принимать текст. | **Fail (Баг)** |
| **TC-CHK-04** | Отмена оформления заказа | На странице ввода данных | 1. Нажать кнопку `Cancel`. | Пользователь возвращается на страницу корзины. Данные не сохраняются. | Pass |

---
### Заметки тестировщика:
- Проверка `TC-CHK-03` выявила критический баг (BUG-003), который блокирует завершение заказа для пользователя `problem_user`.
